# Tawafuq (توافق)

> An accessibility-focused job platform that helps job seekers find and match with opportunities through a voice-driven, inclusive experience.


## About

Tawafuq is a mobile job platform built with accessibility at its core for visual impairments individual. It uses speech technology to make browsing, searching, and applying for jobs easier for them.

The name Tawafuq (توافق) means "compatibility" or "a good match" in Arabic, reflecting the platform's goal of matching people with the right jobs.


## Features

- Voice-driven navigation and search using Speech APIs
- Job listings with search and filtering
- Candidate to job matching
- Application tracking
- Accessible, screen-reader friendly interface
- User authentication and profiles


## Built With

- Flutter (cross-platform mobile)
- Firebase (authentication, database, backend services)
- Speech APIs (voice input and output)

## Run Locally

Prerequisites: Flutter SDK installed and a configured Firebase project.

Clone the project:

```bash
git clone https://github.com/R9hd/Tawafuq.git
```

Go to the project directory:

```bash
cd Tawafuq
```

Install dependencies:

```bash
flutter pub get
```

Add your Firebase configuration files:

- android/app/google-services.json
- ios/Runner/GoogleService-Info.plist

[Adjust to match how your project is set up.]

Run the app:

```bash
flutter run
```
